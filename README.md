# Nightclimb Arcade

Terminal arcade collection — **BOUNCE** (Nokia classic) + **SNAKE** (enhanced retro).

```bash
git clone https://github.com/kaushalboii/Nightclimb.git
cd Nightclimb/bounce_game
python3 run.py
```

**Requirements:** Python 3.7+, curses terminal (Linux/macOS/WSL/Terminal.app), 80×24 minimum.
**Windows:** `pip install windows-curses`

See `bounce_game/README.md` for full documentation.
